# CYVANTA — Cybersecurity Services Website

Premium multi-page cybersecurity services website built with semantic HTML5, CSS3, vanilla JavaScript ES6+, GSAP, AOS and optimized WebP assets.

## Run

Open `index.html` directly or serve the folder with a static HTTP server.

## Authentication Demo

Login validates the selected role and email/password, then routes to the matching Admin or Client dashboard. Dashboard pages preserve the role/email through query parameters and browser storage for this frontend-only demonstration.

## Responsive Breakpoints

- Mobile: below 768px
- Tablet: 768px–991px
- Desktop: 992px and above

## Submission

The `CYVANTA` folder is the source project. The technical documentation is included under `documentation/`. For the requested delivery, zip the complete `CYVANTA` folder and submit the ZIP together with the documentation as instructed by the project POC.
